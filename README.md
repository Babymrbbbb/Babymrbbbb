## 🎯 我做什么

- **AI 工程化**：自建模型网关、质检工具，把 AI 从玩具变成生产线
- **提示词工程**：系统化方法论，从"一句话许愿"到"一句话下订单"
- **RAG 知识库**：raw → wiki → RAG 双轨编译层，概念聚合 + 增量编译 + lint 质量门
- **Agent 编排**：多智能体协作、Skill 体系、工作流自动化
- **桌面端交付**：Electron 经营驾驶舱 + AI 调度运维工作台，业务系统集成 + 数据闭环
- **数据驱动运营**：全渠道数据统一口径，每天自动产出三套交付物
- **私域自动化**：标签 + MA + 券，形成"数据→洞察→触达→回流"闭环
- **工具化沉淀**：把工作里的重复动作写成 CLI / 脚本
